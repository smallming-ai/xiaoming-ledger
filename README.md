# 小铭账本（Xiaoming Ledger）

一个以「快速记账、轻松理财」为初衷的 Android 记账应用：通知栏常驻「记一笔」快捷入口，无需无障碍服务、无需悬浮窗权限即可随手记账；并附每日 / 每月消费额度进度条与按 日 / 周 / 月 / 年 的消费统计图表。

> 本项目为个人学习与分享作品，由「小铭同学」使用 AI 辅助（Vibe Coding）从零完成。欢迎 fork、提 Issue、一起改进。

## 功能亮点

- **通知栏常驻「记一笔」**：划下通知栏即可记账，不用打开 App；无需无障碍/悬浮窗权限，权限面最小、更安全。
- **消费额度进度条（可点击修改）**：首页每日额度（默认 ¥60）与每月额度（默认 ¥1800），点击即可修改，超支自动变红提示。
- **按 日 / 周 / 月 / 年 统计**：
  - 扇形统计图：各类金额占比；
  - 频率分布直方图：各类交易次数。
- **自定义支出类型**：首次使用可选择常用类型，也可随时「＋ 新建类型」，支持「长期保留 / 单次应用」。
- **补记过去账单**：记账窗口的「日期」默认取当前页面日期，可翻到昨天/上周等页面补记，也可在记账窗口手动改日期。
- **删除记录**：列表每行有删除按钮，误记可随时删。
- **本地数据**：账目仅保存在本机 Room/SQLite，不联网、不上传。

## 技术栈

- Kotlin + Android View（XML）
- Material Components
- Room（本地数据库）
- MPAndroidChart（图表）
- AGP 8.2.2 / Gradle 8.2 / Kotlin 1.9.22 / compileSdk 34 / minSdk 26（Android 8.0+）

## 构建 & 安装

1. 安装 **Android Studio**（最新稳定版，自带 JDK 17 与 Android SDK）。
2. 打开工程：`File → Open`，选择本文件夹 `Bookkeeper`。
3. 首次打开会自动同步 Gradle 8.2，请等待完成。
4. 连接手机（开启「开发者选项 + USB 调试」），点工具栏 **Run ▶** 安装；或 `Build → Build APK(s)` 生成
   `app/build/outputs/apk/debug/app-debug.apk` 后手动安装。
   - 要求手机 **Android 8.0 及以上**。

## 使用

1. 首次打开会进入「设置你的记账本」引导页：勾选常用支出类型（可多选）、可添加自定义类型、设置每日消费金额。
2. 首页可见每日/每月消费额度进度条，点击可修改额度；右上角菜单也有「每日额度 / 每月额度 / 使用说明 / 使用须知」。
3. 划下通知栏点「记一笔」，或点首页右下角「＋」，填金额、选类型即可记账；「日期」默认取当前页面日期，可手动改以补记过去。
4. 切到「日 / 周 / 月 / 年」，用左右箭头翻看历史周期的扇形图与直方图。
5. 账目列表每行右侧有删除按钮，可删除误记记录。

## 隐私说明

- 本应用仅保留一个「通知」权限用于通知栏常驻记账；不读取屏幕、不使用无障碍/悬浮窗。
- 所有账目数据仅保存在本机数据库，不联网、不上传。

## 已知限制

- 因微信等支付 App 的隐私保护，支付完成页不暴露给无障碍节点树，故本应用不提供「自动识别支付成功」功能，改以通知栏手动记账，兼顾即时性与隐私安全。
- 卸载应用会清空本机账目数据。
